# Task3 · 验电笔起始摆放分布

**[打开在线分析报告](https://pangye202264690373.github.io/southgrid-task3-distribution/)**

184 段录制的首帧分析，使用集群直接复制的数据。支持按批次、朝向和审阅状态筛选，切换原始首帧与定位叠图。

## 主要发现

- V2：笔尖、笔尾先作同一个透视变换，再在校正坐标中求中心和朝向。
- 73.4% 的目标中心位于白框中间一排；后缘一排为 9.8%。
- 72 个位置×朝向组合中，21 格无样本，53 格不超过 2 段。
- 用户确认的三态：黄色面朝上17、黑色面朝上44、侧向123；#013已纠正为侧向，不使用黄色像素比例分类。
- 新增九宫格玫瑰图：每格N表示位置数量，固定方位扇区面积表示朝向频率，三种颜色表示状态。支持批次、状态筛选及比例/绝对数量切换。

## 内容

- `index.html`：交互报告；`figures/`：分布图；`annotated/`：184 张定位叠图；`rectified/`：184张白框校正图。
- `frames/`：仅 184 张头左首帧，不包含完整视频或原始数据集。
- `placements.csv`：逐段测量；`collection_plan.csv`：逐格补采建议。
- `inventory.json`：公开首帧来源标识与 SHA-256。
- `algorithm_raw.json`、`manual_review.json`、`final_detections.json`：算法结果及复核记录。
- `state_annotations.json`：184段三态标签、确认基准与证据视角；`geometry_config.json`：几何口径与长宽比假设。

## 方法与限制

颜色连通域、白色笔尖和直线特征定位验电笔，白框透视归一化后统计位置。全部184张叠图经目视复核，138张保留算法结果，46张补标或修正。

主统计采用单位正方形白框坐标。用户说明真实横向略长，但精确比例未知，因此角度是“归一化框内朝向”，不是标定后的物理角度；报告给出1.0/1.1/1.2/1.3假设比值的敏感性对照。

三态基准：#068黄色面朝上，#072黑色面朝上，#000及#013侧向，均经用户确认。184段笔身裁片目视复核，41段辅助检查其他首帧视角。状态是粗粒度图像证据标签，不是连续滚转角或完整6D姿态估计。

主对象是白框内可见验电笔，补采范围限定在白框内。模型能力风险是数据覆盖推测，不是已测得的失败率。未进行训练。

此仓库是公开查看版。完整本地审计包括1104张采样图；完整复现材料和额外参考帧保留于本地交付包。公开版将集群账户绝对路径替换为逻辑标识，未包含登录凭据。
